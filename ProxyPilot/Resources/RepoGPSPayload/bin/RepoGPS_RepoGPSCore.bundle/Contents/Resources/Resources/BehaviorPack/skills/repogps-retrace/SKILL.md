# Retrace

Use this when arriving, resuming, after compaction, or when saved context may be
stale. Establish the repository root, worktree, branch, HEAD, dirt, nested
instruction hierarchy, current-state documents, active plans, and the most
recent RepoGPS handoff from current evidence. Quote human intent with its
provenance. Label saved Navigator notes as interpretations.

Compare the fresh observation with the previous observation and report the
delta. An external edit, changed HEAD, or newly dirty path supersedes an older
snapshot. Never treat a historical test result as current verification.

Do not create governance files merely because they are absent. Keep the return
briefing compact: purpose, surrounding constraints, what was underway, what
changed since departure, verified progress, unresolved work, and the next safe
action. Record an advisory Navigator note only when this understanding changes.

Read the closest repository instructions, branch and worktree state, current plans, recent durable history, and the latest handoff. Distinguish selected, configured, stored, and live evidence. Do not edit, test, commit, push, deploy, or write durable state.

Return a compact orientation card containing repository, branch, worktree condition, instruction hierarchy, active work, last verified state, risks, and the next safest action.
