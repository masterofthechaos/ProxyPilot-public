# Resurface

Use this after meaningful dormancy or when old notes conflict with the live
repository. Measure elapsed repository activity from Git rather than guessing.
Read current instructions and status documents before old plans, audits, or
handoffs. Separate durable decisions from state that could have drifted.

Produce a season delta: the last confirmed objective, live HEAD and worktree,
material changes since the prior observation, assumptions invalidated by those
changes, unresolved questions, and the next evidence needed. Preserve unrelated
dirt and do not implement fixes while resurfacing.

If no governance exists, explain the repository from the evidence available.
Absence is not authorization to scaffold. Record uncertainty as Navigator
interpretation; never promote it to observed fact.

Begin with Retrace. Use deterministic history when available to compare the current silence with the repository's own cadence. Re-read durable invariants and current-state sources, inspect changes since the last trustworthy handoff, and label remembered assumptions as confirmed, superseded, or unresolved.

Produce a Season Delta and recommended re-entry sequence. Do not implement repairs during resurfacing.
